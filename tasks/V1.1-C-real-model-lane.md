### 实测结论（模型确认）

- 仓库内置 models.dev 参考快照（`docs/ideas/data/models.dev-api.json` opencode-go 项，2026-09）列出
  35 个模型 id，其中 **`mimo-v2.5`** 与 **`mimo-v2.5-pro`** 在列（另有 `mimo-v2-pro`、`mimo-v2-omni`）。
  目标模型采用 `mimo-v2.5`（flash 档）与 `mimo-v2.5-pro`（pro 档）作为默认，**live `/v1/models` 拉取为准**。
- 因为无法实测（无 key），**真实 MIMO V2.5 清单确认：pending**。`selectMimoModel` 支持"精确 mimo-v2.5 →
  V2.5 系回退 → 任一 MIMO → null"的确定性选择，真实拉取后自动按其确认。

### 设计选择与踩坑

1. **preset SSOT 复用**：直接在 `apps/cli/src/index.ts` 公开 `findPreset`/`fetchOpenAIModels`，bench-runners
   经 `@vessel/cli` 调用，避免第二份 baseUrl 常量漂移。`apps/cli` 本就在 bench-runners 的 tsconfig references 内。
2. **密钥只读落地**：`OPENCODE_API_KEY` 只经 `keyResolver`（默认 env）读取，全链路无写盘调用；无 key → resolver
   返回 null → lane `pending-environment`，不 throw、不触真实 API。
3. **可注入 = 契约友好**：fetch 与 keyResolver 均可注入，单测用固定 test key + 假 fetch，杜绝真实 HTTP。
4. **踩坑**：早期文档 `V1.1-ROADMAP.md` 把环境变量误写为 `OPENGODE_API_KEY`（多一个 G）。本卡/预设/models.dev
   一致使用 **`OPENCODE_API_KEY`**，已顺手修正 ROADMAP 文案并在卡片注明（勿混指挥侧改动）。
5. **踩坑**：`selectMimoModel` 对非 V2.5 的 MIMO 系取 lexicographic 最小（确定性），测试初版断言写错期望值，
   已按实现修正断言（实现为确定性选择，非 bug）。
