# T316 — Web 预设改为生成物（单一真源）

> 自包含执行书。项目根 `E:\Code_file\Projects\Vessel_Harness`（Windows）。
> 目标：`packages/application/src/providers/presets.data.ts` 是唯一真源；Web 的预设目录不再手抄。

## 0. 先读这些（只读）

1. `packages/application/src/providers/presets.data.ts`（152 行，导出 `PROVIDER_CATALOG` / `PROVIDER_CATEGORY_LABELS` / `findPreset` / 类型）。
2. `apps/web/src/components/providers/presetsData.ts`（161 行，`PROVIDER_PRESETS_CATALOG` / `PRESET_CATEGORIES` / `localizePreset` / 类型 `PresetInfo`）。
3. `apps/web/src/components/providers/presetsData.test.ts`（27 行，现已用「读 application 源码文本 + 解析 `{ id:` 行」的方式做同步断言）。
4. `apps/web/package.json`（**只有 react/react-dom，不依赖任何 @vessel 包**——所以不要让 Web 直接 import application）。
5. `apps/web/vite.config.ts` 与 `apps/web/tsconfig.json`（确认 Web 的编译边界）。

## 1. 做法（写死）

1. 新增 `scripts/sync-web-presets.mjs`（Node，零依赖，用 `tsx` 跑）：
   - `--check`（默认）：用与现有测试相同的方式（读 `presets.data.ts` 源码、解析 `{ id:` 行）生成期望内容，与 `apps/web/src/components/providers/presets.generated.ts` 逐字比对；不一致 → 打印 diff 摘要并 exit 1。
   - `--write`：生成/覆盖 `presets.generated.ts`。
   - 生成文件头写：`// GENERATED by scripts/sync-web-presets.mjs — do not edit; run --write.`
2. `apps/web/src/components/providers/presets.generated.ts`（新文件）：导出纯数据 `PROVIDER_PRESETS_CATALOG`（类型保持 Web 现有的 `PresetInfo` 形状，必要时在 generated 文件里也导出该类型或从 presetsData re-export）。
3. `presetsData.ts` 改为薄壳：`export { PROVIDER_PRESETS_CATALOG } from './presets.generated'` + 保留 `localizePreset` / `PRESET_CATEGORIES` 等 UI 派生逻辑（它们从数据推导，不手写条目）。
4. `presetsData.test.ts` 的同步用例改为调用生成脚本的 `--check`（或复用同一解析函数），不再各自实现一套解析。

## 2. 不许做

- 不给 `apps/web` 增加 `@vessel/*` 依赖，不改 Vite alias。
- 不手改生成文件（它是产物）。
- 不改预设内容（条目、字段、顺序、i18n 文案全部保持现状）。
- 不 commit / push；不加依赖；不动 `packages/core`。
