## 3. Acceptance Criteria (验收标准)

1. 每条覆盖项都有结论：`通过` / `不通过（附现象）` / `无法验证（附原因）`，不允许「看起来可以」。
2. 每个结论至少配一张截图或一段 DOM 观测（选择器 + 实际值），文件落在 `evidence/sessions/2026-10-23-browser-acceptance/`。
3. UI-10 矩阵至少覆盖：宽度 360 / 768 / 1024 / 1440 / 1920；主题 浅/深；语言 中/英；缩放 100% 与 150%。每格记录是否出现横向溢出、文字截断、遮挡。
4. 删除与 Activity 的场景必须用夹具工作区里新建的会话，事后确认该夹具目录仍可安全丢弃。
5. 结束时服务已停止，端口已释放。
