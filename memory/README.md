# Memory

Long-term project memory for **Composable_Agent_Harness** — things an agent cannot
reliably re-derive from the repo, and that are prone to recur if forgotten.

Created 2026-09-24 as part of the personal-dev-workflow v1.0.0 layout unification.

## What belongs here

- Stable project rules and invariants (see `AGENTS.md` for the canonical map).
- Real lessons: mistakes that actually happened, are likely to recur, and are costly.
- Handoff notes that carry context not inferable from the repo.

## What does not

- Task semantics and acceptance → `tasks/` cards.
- Code facts → git diff / commits.
- Verification evidence → `evidence/`.
- User-visible shipped changes → `CHANGELOG.md`.
- Throwaway process notes → `DEV_LOG.md`.

Per `memory-policy.md`: store each fact in its single best place. When there is no
reusable lesson, not writing anything is the correct behavior.
