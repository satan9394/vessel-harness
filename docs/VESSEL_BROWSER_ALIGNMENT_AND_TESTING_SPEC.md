## 1. Codex 浏览器实测准备与启动指引

Codex 在执行本任务时，应当在本地执行以下步骤拉起测试环境：

### 1.1 服务启动
执行以下命令拉起 Vessel 本地全功能服务（托管已构建的前端静态资源与 API）：
```bash
npx tsx apps/cli/src/cli.ts serve --port 5678
```
服务成功监听在 `http://127.0.0.1:5678`。

### 1.2 浏览器接入
使用 Codex 内置的浏览器自动化工具 / 浏览器控制插件访问：
`http://127.0.0.1:5678`

## 2. 核心浏览器测试用例（Step-by-Step 交互实测清单）

Codex 必须按顺序操控内置浏览器执行以下交互，并记录实测表现与截屏：

### 测试 1：全屏工作台工业美学与深浅主题实测
1. 观察进入页面后的默认布局：
   - 是否呈现标准的 Edge-to-Edge（顶天立地、通栏贴边、无四周冗余留白缝隙）？
   - 所有的区域分割线是否为整洁硬朗的 1px Hairline 实线？
   - 是否已经彻底消除了旧版圆角过大的弧形悬浮孤岛卡片？
2. 实体按键交互：
   - 鼠标悬停（Hover）与点击（Active）主按钮、输入框发送键、标签切换键；
   - 验证是否有明确的实体边框、按压位移（TranslateY 1px）或微阴影反馈，手感是否扎实。
3. 主题切换测试：
   - 点击右上角或设置中的主题切换按钮（Dark ↔ Light）；
   - 检查浅色模式下文字对比度是否达标，是否存在发白、不可见或边框混淆；
   - 检查深色模式下背景是否深邃均匀，是否存在刺眼高亮。

### 测试 2：输入法 (IME) 与输入框交互实测 (验证 F7 修复)
1. 聚焦中央主输入框；
2. 模拟中文/日文输入法（IME）输入拼音字符串（如 `ceshi`）并不立即确认；
3. 按下键盘 `Enter` 键选词；
4. **硬性断言**：页面是否**绝对不会**提早触发 `<form onSubmit>` 发送半截拼音？
5. 选词完成后再次按下 `Enter` 键，验证是否能正常触发消息发送。

### 测试 3：会话创建与原子化物理删除实测 (验证 Task 248/250 修复)
1. 在左侧栏或首页点击“+ 新建任务”或发送一条消息，生成一个新会话；
2. 观察左侧会话列表中是否正常出现该会话项；
3. 鼠标悬停在该会话项上，点击“删除（垃圾桶图标）”；
4. 观察系统确认弹窗或二次确认行为：
   - 点击“取消”，验证会话保留，列表不变；
   - 再次点击“删除”并确认；
5. **硬性断言**：
   - 列表是否在服务端完成 Windows 回收站处理后确凿移除了该项？
   - 刷新浏览器页面（F5 / Reload），该已删除会话是否**绝对不会**复活变成幽灵会话？

### 测试 4：Activity 待办中心与状态真实性实测 (验证 F1 修复)
1. 点击导航栏中的 “Activity” 视图；
2. 查看当前列出的 Run 与 Session 记录：
   - 检查状态标签：是否存在无 terminal 证据就擅自标绿显示“completed”的虚假回执？
   - 观察失败、待处理（Needs Attention）、运行中与已完成条目的分组和排序；
3. 点击任意 Activity 卡片，验证是否能正常导航至该会话详情，是否存在点击后页面崩溃或 404 的情况。

### 测试 5：模型供应商中枢 (Provider Hub) 免输直测实测 (验证 F2 修复)
1. 进入 “Settings” → “模型供应商” 页面；
2. 找到一个已配置有凭据的供应商（或新增一个测试项）；
3. 点击“测试连接”按钮；
4. **硬性断言**：
   - 请求体是否为免输 key 模式（`apiKey: ''`）？
   - 控制台或网络抓包中是否证实请求地址被严格锁定在服务端真实 `baseUrl`，绝无篡改跳转？
   - 测试连接返回状态与响应时间是否真实准确反馈。

### 测试 6：Agent Studio 与 Inspector 细节审查 (审查 UI-05 / UI-06 遗留项)
1. 点击进入 “Agent Studio” 模块；
2. 检查规则组合器、行为编译器与 Agent Profiles 界面：
   - 界面上是否有误导性的“已验证即生效”暗示，还是清晰区分了暂存预览与实际激活？
3. 打开侧边 Inspector（检查器）抽屉：
   - 观察当前的 8 个标签（swarm、context、cache、ast、diff 等）；
   - 评估其平级展开对日常代码审查任务的认知负荷，记录精简/折叠优化的具体建议。
