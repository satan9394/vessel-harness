## 1. 不可协商的硬约束

1. **颜色只写 CSS 变量**；浅色值放 `:root`，深色值放 `:root[data-theme="dark"]`（并保留 `@media (prefers-color-scheme: dark)` 作为无 JS 回退）。禁止组件里硬编码 hex。
2. **浅色为默认，深色可跟随系统或手动切换**；保留用户主题偏好。实现见 `apps/web/src/utils/theme.ts`。
3. **不引入 Tailwind / 新依赖 / 非 npm 锁文件**。依据 `docs/DESIGN-DECISIONS.md` 决策点 19。
4. `packages/core` 零改动；Web 构建携带 `-- --emptyOutDir false`。
5. 中英双语与响应式不回退。

## 2. 视觉：玻璃（Glass）

### 2.1 颜色

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#E4E8F3` | `#06070D` | 应用底（面板之间的可见光场） |
| `--panel` | `#FFFFFF` | `#0D0F18` | 面板表面 |
| `--panel-2` | `#F2F4FB` | `#131725` | 次级面：输入、工具行、悬停 |
| `--panel-3` | `#E4E8F5` | `#1A1F30` | 结构面：bezel 外壳、进度底 |
| `--ring` | `rgba(38,44,80,.08)` | `rgba(255,255,255,.08)` | 发丝描边（**取代 1px 灰线**） |
| `--ring-2` | `rgba(38,44,80,.16)` | `rgba(255,255,255,.16)` | 控件描边 / 悬停 |
| `--text` / `--text-2` / `--text-3` | `#0C1020` / `#525A73` / `#858CA3` | `#EEF0F8` / `#98A0B8` / `#6A7288` | 主 / 次 / 元信息 |
| `--accent` / `--accent-fg` | `#5B6CFF` / `#FFF` | `#9BA6FF` / `#0A0C18` | 主操作 / 活跃态 |
| `--accent-soft` | `rgba(91,108,255,.10)` | `rgba(155,166,255,.14)` | 选中 / 活跃背景 |
| `--ok` / `--warn` / `--danger` | `#0F7A55` / `#8A6100` / `#B4292E` | `#4ADE94` / `#F4C151` / `#FF7C72` | 成功 / 待审批 / 失败 |
| `--glow-a` / `--glow-b` / `--glow-c` | 紫 / 薄荷 / 蜜桃，见原型 | 同色更深 | 应用底色光场（**只用于 `body::before`**） |

**玻璃质感**：`--glass: color-mix(in srgb, var(--panel) 78%|82%, transparent)`；顶栏与图标轨用 `backdrop-filter: blur(26–28px) saturate(1.7)`。**只对固定/吸顶元素用 blur，绝不用在滚动容器上。**

### 2.2 尺度

- 圆角：`14`（控件）`18`（卡片）`24`（面板）`30`（外壳）`999`（胶囊）
- 间距：`4 / 8 / 12 / 16 / 22 / 32 / 48`
- 字号：`10.5 / 11.5 / 12.5 / 13.5 / 15 / 16 / clamp(24–32)`；基准 13.5px，行高 1.55
- 字距：正文 `-.006em`；大标题 `-.03em`；小标签 `+.18em` 且全大写
- 层级：`--shadow-1`（卡片）/`--shadow-2`（面板）/`--shadow-3`（浮层）；一律**大范围低透明度**，禁止硬投影
- 内高光 `--hl: inset 0 1px 0 rgba(255,255,255,.9|.07)`
- 动效：`--ease: cubic-bezier(.32,.72,0,1)`；微交互 300ms，面板级 500ms，入场 800ms

### 2.3 字体

`"Geist"` 无衬线 + `"Geist Mono"` 等宽（Google Fonts，带系统回退）。数字统一 `tabular-nums`。
**已知限制**：Geist 无中日韩字形，中文回退系统 CJK 字体，字体性格对中文只部分成立。

## 3. 信息架构：为什么是四栏

| 借鉴对象 | 取它的什么 |
|---|---|
| **Codex** | 左侧线程/项目列表 + 中央过程 + **独立右侧审阅栏**；以及**审批档位**（suggest / auto-edit / full-auto）做成输入区胶囊 |
| **Claude Code** | **常驻计划清单（todo）** 让人随时知道"到哪一步了"；**改文件前先就地给 diff 并可采纳/拒绝**；**上下文余量计量**常驻 |
| **OpenCode** | 键盘优先 + `/` 与 ⌘K 命令面板；底部状态行；多会话并行 |
| **Cursor / Zed / Antigravity / Devin** | 多任务列表 + 中央过程 + 审阅面的稳定共识；Devin 式"计划 → 步骤 → 产物"叙事 |

**被否决的**：**无侧栏的「聚光」外壳**。它好看，但多会话/多项目一多就撑不住——上述产品没有一个敢去掉会话列表。
「舱位 bento」下沉到**活动页**（多会话监控本就是 bento 的强项）；「时间轴」下沉到**追踪 Tab**（作二级视图很强，作主视图伤日常流程）。

## 4. 骨架规格（四栏）

```
[58px 图标轨] [232px 会话/项目栏] [中央：过程 + 输入] [300px 审阅栏]
```

| 栏 | 宽度 | 职责 | 折叠 |
|---|---|---|---|
| 图标轨 | 58 | 全局区域导航 + 命令面板入口 + 品牌 | 永不折叠 |
| 会话/项目栏 | 232 | 项目分组、会话列表（带状态点）、搜索、新建会话 | ≤1180px 收起为抽屉 |
| 中央 | 剩余 | 顶栏（标题/状态/计划进度/操作）+ 过程流 + 输入区 | 主体 |
| 审阅栏 | 300 | **画布检视器**：真实 8 Tab（代理网络 / 认知规则 / 上下文 / 模型缓存 / 影响范围 / 代码补丁 / 任务树 / 追踪；详见 §4.3） | ≤1180px 收起为浮层，≤1023px 转模态 |

### 4.1 中央过程流（顺序固定）

1. **计划清单**（常驻，置顶）：`✓ 完成 / ● 当前 / · 待办`，右侧显示耗时；标题显示 `计划 · 3 / 5`。
2. 用户消息 → 助手思考折叠 → 工具行。
3. **就地 diff**：改文件前先给看，带 `采纳这处 / 拒绝 / 在画布中逐块处理`；行内 `+n −n`。
4. **授权卡**：`批准一次 / 本会话内总是允许 / 拒绝`。
5. 循环。

### 4.2 输入区

胶囊行：`项目 / 模型 / 审批档位 / 模式`；下方是双层 bezel 输入框与发送按钮；最下一行是**计量**：上下文占用（带进度条）、缓存命中、花费、计划进度、键位提示。

### 4.3 审阅栏

**实现即「画布检视器」**——权威定义为 `apps/web/src/components/layout/DualSurfaceLayout.tsx` 的
`INSPECTOR_TABS`（**真实 8 个 Tab**），标签取 `i18n.ts` 字典原值：

`代理网络 / 认知规则 / 上下文 / 模型缓存 / 影响范围 / 代码补丁 / 任务树 / 追踪`

- 折叠与开关：`Ctrl/Cmd+I`；持久化键 `vessel.inspector`；≤1023px 转 `role="dialog"` 模态（焦点陷阱 + Esc + 关闭回焦）。
- 各 Tab 承载：缓存效益 + 工作区指纹 + 提示词前缀分段（**模型缓存**）、Context 四层缓存（**上下文**）、
  AST 影响面（**影响范围**）、逐 Hunk 补丁（**代码补丁**）、团队任务树（**任务树**）、结构化 Trace（**追踪**）、
  Swarm 拓扑（**代理网络**）、认知规则看板（**认知规则**）。
- **追踪** Tab 内含时间轴视图（思考 / 工具 / 审批 / 策略四泳道）。
- **本会话变更文件**（`+n −n`、`打开补丁画布 / 导出 diff`）属 **`ChangedFiles` 模块**，**不是**检视器的 Tab。

> **修正记录（2026-10-16）**：本节此前写作「变更 / 上下文 / 追踪」三个 Tab —— 那是早期设计草稿，
> 与实现不符。真实定义以 `DualSurfaceLayout.tsx` 与 `FEATURE-COVERAGE.md`（B9/B15）为准。

## 5. 各区域规格

| 区域 | 主结构 | 关键内容 |
|---|---|---|
| 工作台 | 列表（默认）／舱位（可选） | 项目 → 任务 → 启动；最近会话；项目列表 |
| 会话 | 四栏骨架本体 | 见第 4 节 |
| 画布补丁 | 三栏（文件 / Hunk / 应用） | 逐 Hunk `采纳 / 丢弃 / 恢复`；门禁预检；回滚提示 |
| 活动 | **不对称 bento** | KPI、集中审批队列、团队任务树、Swarm 拓扑、跨项目运行、子代理、沙箱审计、外部评审 |
| Agent Studio | 两栏 | 行为库、组合与冲突检测、L0–L4 兼容阶梯、认知规则看板 |
| 设置 | 纵向分区 | 供应商与模型表（拉取/测试/端点探测/脱敏导出）、策略与权限、工具与 MCP、模块可见性、语言与主题 |
| 全览 | 滚动看板 | 所有模块与两种结构并排，供评审（`data-area="showcase"`） |

**全局浮层**：命令面板（⌘K，语义分组，**不显示内部 ID 与长路径**）、新建会话、偏好抽屉、供应商弹窗。

## 6. `apps/web` 侧需要修掉的"丑"点

1. 满屏 1px 同权重灰框 → 换 `--ring` 发丝 + 面板分层。
2. **裸 slug 与长绝对路径**铺在列表上（`VESSEL-CARD222-FIXTURE-SZVBBY`、`C:\work\AppData\...`）→ 列表只显示可读名 + 项目名，完整值收进详情等宽块。
3. 会话标题用可读标题；时间统一 `HH:mm` / `MM-DD`。
4. 补齐空态（带下一步动作）、加载态（结构骨架）、错误态（就地 + 重试）。
5. Agent Studio 的边框卡片墙 → 收敛为分区 + 去边列表。

## 7. 共有规则（与视觉方向无关）

- **可访问性**：`:focus-visible` 2px 外描边；图标按钮必须有 `aria-label`；颜色不作唯一状态信号；正文对比度 ≥ 4.5:1，禁用态 ≥ 3:1；抽屉/弹层 Escape 关闭并回焦。
- **动效**：只动 `transform`/`opacity`；交互反馈 ≤ 350ms；必须尊重 `prefers-reduced-motion`。
- **响应式**：≤1180px 收会话栏与审阅栏；≤900px 主内容单列；断点是结构切换，不是 `flex-wrap` 兜底。
- **国际化**：全部文案走 `apps/web/src/i18n.ts`；`workspace-write` / `read-only` 等策略名保留英文原样。
