## 结论

- **达成 10 项**、**部分 3 项**（#8 沙箱、#10 Cross-Harness、#11 soak 墙钟）、**阻塞 0 项**（但 #10 的 live 跑与 #8 的受限令牌属外部/超范围）。
- **离 1.0 只差**：① 一次 `--live` 跨 harness 基线（**待配额确认**）→ 定回归阈值；② 刷新 `release-report.{md,json}`（重跑门禁会经 CredentialStore 打真实模型，**待配额确认**）；③ （可选）字面 3h 墙钟 soak。
- **明确不在 1.0 门槛内**（路线排除）：受限令牌降权、非 Windows 沙箱、V2.x（Remote/Cloud/多设备/团队/插件市场）、全量 npm 发布 17 包、provenance/SBOM/changesets、i18n 全量重构。
