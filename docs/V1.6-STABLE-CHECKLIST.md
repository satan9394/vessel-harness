## 结论

- **达成 10 项**、**部分 3 项**（#8 沙箱、#10 Cross-Harness、#11 soak 墙钟）、**阻塞 0 项**（但 #10 的 live 跑与 #8 的受限令牌属外部/超范围）。
- **可自主项**：140–148 已关闭（记忆同步 #3/#4、文档诚实化、方向 B 残留清算、real-IO 超时）；**新增可自主项 150**（修复外部 harness adapter）。
- **离 1.0 只差**：① 一次 `--live` 跨 harness 基线 —— **未做**；`tasks/150`/`151` 的修复与实跑已**回退**（`tasks/153`），本仓**不再自动驱动外部 agent**（见 `AGENTS.md` 禁做清单），如需由用户逐次授权另议；② 刷新 `release-report.{md,json}`（重跑门禁会经 CredentialStore 打真实模型，**待配额确认**）；③ （可选）字面 3h 墙钟 soak。
- **发布准备：已按决策点 21 作废**（2026-09-28 追注）——`docs/RELEASE-NOTES-v1.0.md` 保留为历史草稿；本仓不再创建 GitHub Release、不向 npm 发布新版本，故"停在打 tag 前"不再是待办。本文其余条目（如 #10 的 `--live` 跑、#11 的字面墙钟 soak、#13 的 Packaging gate 最新结果）仍是各自的历史状态记录，需另行判断。
- **明确不在 1.0 门槛内**（路线排除）：受限令牌降权、非 Windows 沙箱、V2.x（Remote/Cloud/多设备/团队/插件市场）、全量 npm 发布 17 包、provenance/SBOM/changesets、i18n 全量重构。
