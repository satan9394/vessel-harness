结构概念（骨架不同，不只是换皮）

三套各自换了信息架构与主视图，而不是同一骨架换配色。

CONCEPT 01

聚光 Command-First

没有侧栏。整页是一条大命令栏 + 实时结果流，运行中的会话沉到底部 dock；会话视图是居中窄列，检查器是浮层抽屉。

CONCEPT 02

舱位 Bento 任务控制台

没有侧栏，改为顶部分段导航；首页是不对称 bento 网格（2×2 运行卡 + 1×2 审批卡 + 2×1 宽卡）；会话是三栏驾驶舱。

打开 舱位 →
CONCEPT 03

时间轴 Timeline DVR

会话不是聊天记录，而是一根横向执行时间轴：思考 / 工具 / 审批 / 策略四条泳道，每步是可点选的时长条，底部可拖拽 scrubber。

打开 时间轴 →
