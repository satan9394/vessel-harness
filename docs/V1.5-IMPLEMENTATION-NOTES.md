## Adaptive compaction and overflow recovery

`computeAdaptiveThreshold` uses `floor(min(calibratedWindow * 0.8, calibratedWindow - maxOutputTokens - buffer))`, including the default CJK calibration factor 0.85. Negative headroom remains negative so an undersized window triggers compaction immediately. Output budget precedence is explicit compaction configuration, provider default, then 4096; the request and threshold use the same budget.

The provider-message whitelist identifies context overflow. Composition injects emergency compaction into `AgentLoop` and isolated runtimes; core has no provider-specific classifier. Recovery permits one retry and cannot replay a request after streamed output. Repeated overflow ends the run even when its token count resembles a generic 5xx error.

## MCP lifecycle

`BoundedStdioTransport` reuses stdio JSON-RPC and the runtime Windows Job Object backend. RPC waits for binding; cleanup retains observed descendant PIDs, verifies disappearance, and falls back through the existing runtime tree termination API after partial attachment or disposal failure.

`LazyMcpClientProxy` performs single-flight initialization on demand. Configured `staticTools` allow schema registration without a process; without a static manifest, discovery must start the server. `vessel mcp disable <name>` and `enable <name>` persist the optional boolean flag; shared assembly skips disabled servers.

Offline tests exercise fake process trees and a 2000ms cleanup deadline. They do not prove native Windows latency: the existing asynchronous Job Object binding can wait up to 30 seconds, with a two-second stdio root-kill fallback during close.

## Staged teams

`TeamRuntime.stageTeam()` validates a DAG and captures immutable model route parameters and the resolved provider binding. `getStage()` returns a compact detached view; only explicit `approve(stageId)` starts execution. `reject()` closes a staged plan without execution. Scheduler transitions are pending → ready → claimed → running → completed/failed; cycles fail immediately, independent branches run concurrently, and failed dependencies block descendants.

Generator dependency evidence reaches the evaluator internally. Parsed rejection/error remains in the review result. Settlement events identify both stage and member; outward output/error previews are limited to 300 characters. Reasoning and temperature reach isolated/delegate requests and provider wire formats.

## Optional streaming archive

`ChunkedSession.open()` provides the exported streaming reader/writer contracts without changing legacy `Session`. Frames use built-in gzip (or raw storage), bounded record buffering, checksums, and sequence indexes. `streamRecords(fromSeq, toSeq)` reads one relevant frame at a time. This optional API does not replace default JSONL loading or establish a whole-application OOM guarantee.

`append()` buffers; `flush()` and `close()` are durability barriers. Recovery indexes durable frames beyond stale metadata, quarantines an incomplete unindexed final frame by rename, and rejects committed/interior corruption. `interrupt()` discards the unflushed tail. Exclusive acquisition prevents competing writers; a dead established writer can be reclaimed. A crash during acquisition itself leaves the claim gate fail-closed and requires operator recovery. Normal release renames ownership metadata; it does not permanently delete user files.

## Offline resilience evidence

The scenario drives 100 actual mock-backed AgentLoop rounds, two tool branches per round, twelve remembered facts, and over 500,000 estimated injected tokens. Faults occur at rounds 30 (overflow), 60 (unresponsive fake MCP), and 90 (archive interruption/reopen). Archive sequence numbers stay monotonic independently of legacy Session sequence numbers.

The independent scorer receives compact facts, hashes, sequences, and fault evidence, not provider identity or producer scores. Negative cases reject missing/corrupt/reordered records, lost facts, duplicate rounds, and cleanup residue. Scratch files are retired through an injected operation; tests permanently clean only their own system-temp fixtures.

Observed score: completion, fact preservation, recovery, data integrity, and overall preservation all 100%; orphan processes and workspace residue both zero. No installed external agent or live model is used. No native compression dependency was added; `npm ci --offline` passed with zero audit vulnerabilities.
