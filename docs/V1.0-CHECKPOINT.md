## 5. 已知技术事实（续跑时勿重复踩）

- 系统无 tool/call、audit/denial 的 bus emit（那些是 session 持久记录 B## 非事件）；投影用 before_tool/after_tool/policy_decision（040 已验证）
- MockProvider 返回 {text} 形状，server SSE 的 after_model 只在 response.content/toolCalls 时发 delta——mock 冒烟看不到 conversation/usage delta，真实 provider 才有（042 报告）
- Anthropic stream 的 input_json_delta 帧不带 tool id，parser 用 content_block index→id 映射补全（046 已处理）
- CredentialStore 的 DPAPI 在 Windows 实测可用（spawn powershell ProtectedData）；非 Windows 显式降级 plaintext + warn
- 全量 vitest 偶发 Windows 原子写 rename EPERM（usage-store 等），isolate 重跑即绿，非回归
- apps/web 不进 root tsconfig references / root vitest include（独立 vite config + 独立 vitest.config）
